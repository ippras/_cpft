# Фактор селективности ($\alpha$)

$$\alpha = \frac{k'_{i + 1}}{k'_i}$$

* если $k'_{i + 1} > k'_i$, то для разделения требуется, чтобы $\alpha > 1$.
* если $k'_{i + 1} < k'_i$, то для разделения требуется, чтобы $\alpha < 1$.

**Фактор селективности** (также называется **фактор разделения**,
**относительное удерживание**, **фактор ёмкости**, **альфа**) характеризует
термодинамическое разделение двух пиков. Он используется для оценки разности
факторов удерживания ($k'$) двух компонентов и определения возможности их
разделения.
