

## Compound mining

### 1. Auto-Select Compound Mining
Это интеллектуальный режим, который программа использует по умолчанию.
*   **Принцип работы:** Программа автоматически выбирает наиболее подходящий алгоритм поиска соединений, основываясь на типе загруженных данных (например, GC/MSD, GC/Q-TOF или GC/QQQ).
*   **Когда использовать:** Рекомендуется для большинства стандартных задач, когда вы хотите, чтобы система сама определила оптимальный метод обработки данных.

### 2. Find by Chromatogram Deconvolution (Деконволюция хроматограмм)
Этот алгоритм предназначен для идентификации соединений в сложных смесях.
*   **Принцип работы:** Алгоритм анализирует хроматограмму, выделяет пики и создает «очищенный» масс-спектр для каждого соединения, отделяя его от фонового шума и соэлюирующих (выходящих одновременно) компонентов.
*   **Ограничения:** Может использоваться только для данных, полученных в режимах **Scan**, **Product Ion scan** или **Neutral Loss scan**.
*   **Настройки:** Пользователь может задавать порог сигнал/шум (SNR threshold) и параметры дельта-масс (m/z delta) для точного или номинального масс-спектрометрического разрешения.

### 3. Find by MRM (MRM only)
Специализированный алгоритм для данных, полученных на тройном квадруполе (Triple Quadrupole).
*   **Принцип работы:** Программа ищет соединения, используя заданные переходы MRM (Multiple Reaction Monitoring). Все соединения, описанные в методе сбора данных, извлекаются и отображаются в списке соединений (Compound List).
*   **Особенности:** В отличие от других методов, здесь соединения не отсеиваются на основе результатов интеграции хроматограмм — извлекаются все, что соответствуют заданным переходам.
*   **Когда использовать:** Только для файлов данных, полученных с использованием MRM-переходов.

### 4. Find by Integration
Алгоритм, основанный на классической интеграции хроматографических пиков.
*   **Принцип работы:** Программа выполняет интеграцию хроматограммы (TIC или EIC), и для каждого идентифицированного интегратором пика создается отдельное «соединение» (compound).
*   **Когда использовать:** Подходит для простых задач, где достаточно стандартного обнаружения пиков по их площади или высоте.

### 5. Find by Fragments
Алгоритм, разработанный специально для данных **GC/Q-TOF EI** (электронная ионизация).
*   **Принцип работы:**
    1.  Выбирает «n» наиболее характерных фрагментных ионов из спектральной библиотеки.
    2.  Извлекает хроматограммы этих ионов в узком временном окне.
    3.  Ищет группы пиков, которые выходят одновременно (кластеризуются по времени удерживания).
    4.  Выбирает опорный ион (reference ion) и подтверждающие фрагменты.
    5.  Рассчитывает коэффициент соэлюирования (coelution score).
*   **Результат:** Создается "Cleaned HighE Scan", содержащий только опорный и подтверждающие ионы.

---

**Важное примечание из руководства:**
*   Доступность этих алгоритмов зависит от типа загруженных данных. Например, если открыты только файлы MRM, программа предложит только алгоритм *Find by MRM*.
*   Выбор алгоритма осуществляется в окне **Method Editor** в разделе **Method Automation > Workflow**.
